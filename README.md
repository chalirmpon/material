# ระบบคลังวัสดุ — หน้าเปิดระบบ (GitHub Pages)

หน้าเว็บกลางไฟล์เดียว ใช้ร่วมได้ทุกหน่วยงานที่ใช้ระบบคลังวัสดุ — ไม่มีแถบ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script" เปิดกล้องสแกน QR / บาร์โค้ดแบบสดได้ และติดตั้งเป็นแอปบนมือถือได้

**วิธีใช้:** เปิด `https://chalirmpon.github.io/material/?api=` ตามด้วยลิงก์ Web app (`…/exec`) ของหน่วยงาน — ครั้งแรกครั้งเดียว เครื่องจะจำไว้ ครั้งต่อไปเปิด `https://chalirmpon.github.io/material/` ได้เลย
ข้อมูล ผู้ใช้ และรหัสผ่านอยู่ในระบบ Apps Script ของแต่ละหน่วยงานเหมือนเดิม ไฟล์นี้มีแค่หน้าเปิดระบบ ไม่มีข้อมูลหรือลิงก์ของหน่วยงานใด

**ฝั่งหน่วยงาน:** เพิ่มไฟล์สคริปต์ `WebGitHub` (วางไว้หลังไฟล์ `Code`) ในโปรเจกต์ Apps Script ของระบบคลังวัสดุ → Deploy › Manage deployments › แก้ไข › New version › Deploy (ผู้มีสิทธิ์เข้าถึง: ทุกคน) → ลิงก์และ QR สำหรับเจ้าหน้าที่อยู่ที่ ⚙️ ตั้งค่า → 🔌 เชื่อมต่อ

**ติดตั้งเป็นแอป:** Android — Chrome → ⋮ → ติดตั้งแอป • iPhone — Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม • คอมพิวเตอร์ — Chrome / Edge → ไอคอนติดตั้งในแถบที่อยู่

**ตั้งค่า GitHub Pages (ครั้งเดียว):** repo สาธารณะชื่อ `material` → อัปโหลด `index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `.nojekyll` → Settings › Pages › Branch: `main` / `(root)` → Save (ที่อยู่ตัวพิมพ์เล็ก `/material/`)

พัฒนาโดย นายเฉลิมพล ศรีนวลแสง นวก.สธ.ชพ.
